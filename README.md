# ⚽ Football Player Performance Rating Prediction

A Machine Learning project that predicts football player performance ratings
using statistics from top European football leagues.

## 📌 Project Overview

The project uses player statistics such as goals, assists, expected goals,
shots, tackles, interceptions, saves and other performance metrics to predict
a player's overall performance rating.

## 🧠 Machine Learning Models

- Linear Regression
- Random Forest Regressor
- XGBoost Regressor

XGBoost achieved an R² score of approximately 0.497 on the test set.

## 📊 Dataset

- 8 European football leagues
- 3,703 clean player records
- 22 engineered/model features

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Streamlit

## 🚀 Streamlit App

The application allows users to select a football player and view:

- Player information
- Actual rating
- Predicted rating
- Prediction difference
- Performance statistics
